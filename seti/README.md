# lan_copies — обнаружение копий приложения в локальной сети

Приложение находит свои копии, запущенные в локальной сети, с помощью обмена multicast UDP-сообщениями. Оно отслеживает появление и исчезновение копий и при каждом изменении выводит список IP-адресов «живых» копий.

Адрес multicast-группы передаётся параметром. Протокол (IPv4 или IPv6) выбирается автоматически по этому адресу.

## Возможности

- Работа в IPv4 и IPv6 сетях с автоматическим выбором протокола по адресу группы.
- Обнаружение появления копий и их исчезновения:
  - при штатном завершении (Ctrl+C, `SIGTERM`) копия отправляет сообщение `BYE` и сразу удаляется из списков;
  - при аварийном завершении (`kill -9`, обрыв сети) копия удаляется по таймауту, если от неё 5 секунд не было сообщений.
- Различение нескольких копий на одном компьютере: у них общий IP, но разные идентификаторы.
- Вывод списка только при изменении состава копий.
- Необязательный выбор сетевого интерфейса.
- Трафик ограничен локальным сегментом (TTL / Hop Limit = 1).

## Требования

- Linux;
- компилятор с поддержкой C++17 (GCC 7+ или Clang 5+);
- CMake 3.10+.

```bash
sudo apt install build-essential cmake
```

## Сборка

```bash
cmake -B build
cmake --build build
```

Исполняемый файл: `build/lan_copies`.

## Запуск

```
lan_copies <адрес multicast-группы> [порт] [интерфейс]
```

| Параметр | Обязательный | По умолчанию | Описание |
|---|---|---|---|
| адрес группы | да | — | IPv4 (`224.0.0.0/4`) или IPv6 (`ff00::/8`) multicast-адрес |
| порт | нет | `30000` | UDP-порт, 1–65535 |
| интерфейс | нет | выбирает ОС | имя сетевого интерфейса, например `enp0s3` |

Для IPv6 интерфейс можно указать и через зону в адресе: `ff02::4321%enp0s3`.

### Примеры

```bash
# IPv4
./build/lan_copies 239.192.0.1
./build/lan_copies 239.192.0.1 40000
./build/lan_copies 239.192.0.1 30000 enp0s3

# IPv6
./build/lan_copies ff02::4321%enp0s3
./build/lan_copies ff02::4321 30000 enp0s3
```

Для link-local групп IPv6 (`ff02::…`) интерфейс рекомендуется указывать всегда. Без него программа выведет предупреждение, а на машине с несколькими интерфейсами может выбрать не тот.

Выход — Ctrl+C.

## Протокол

Сообщения передаются UDP-датаграммами на адрес группы, в текстовом виде:

```
LAN_COPIES_V1 <тип> <id>
```

| Поле | Значение |
|---|---|
| `LAN_COPIES_V1` | метка протокола и его версия; отсекает посторонние пакеты |
| тип | `HELLO` — «я работаю», `BYE` — «я завершаюсь» |
| id | случайный 64-битный идентификатор копии, 16 hex-символов |

- Каждая копия отправляет `HELLO` раз в **1 секунду**.
- Копия считается исчезнувшей, если от неё нет сообщений дольше **5 секунд**.
- При штатном завершении копия отправляет `BYE`.
- Сообщения, не совпадающие с форматом в точности (лишние поля, пробелы, неверный ID), отбрасываются.
- Свои собственные сообщения копия распознаёт по ID и игнорирует.

## Структура проекта

| Файл | Содержимое |
|---|---|
| `main.cpp` | точка входа, обработка ошибок верхнего уровня |
| `app.h/.cpp` | разбор аргументов, обработка сигналов, главный цикл |
| `multicast_socket.h/.cpp` | multicast UDP-сокет для IPv4/IPv6: разбор адреса группы, вступление в группу, отправка и приём |
| `protocol.h/.cpp` | формат сообщений, сборка и разбор, генерация ID, интервал и таймаут |
| `peer_table.h/.cpp` | таблица живых копий, удаление по таймауту, вывод списка |
| `announcer.h/.cpp` | отправка `HELLO` и `BYE` |
| `listener.h/.cpp` | приём и обработка входящих сообщений |
| `common.h/.cpp` | общие вспомогательные функции |
| `CMakeLists.txt` | сборка |

## Проверка

1. **Появление.** Запустить программу с одной и той же группой на нескольких машинах. Каждая копия выведет список остальных.
2. **Штатное исчезновение.** Нажать Ctrl+C на одной из копий. У остальных она сразу пропадёт из списка.
3. **Аварийное исчезновение.**
   ```bash
   ./build/lan_copies 239.192.0.1 &
   kill -9 %1
   ```
   У остальных копий она пропадёт примерно через 5 секунд.
4. **Несколько копий на одной машине.** Запустить программу в двух терминалах одного компьютера. В списке будут одинаковые IP с разными ID.
5. **Разные группы.** Копии, запущенные с разными адресами групп, друг друга не видят.
6. **Ошибки параметров.**
   ```bash
   ./build/lan_copies                          # справка
   ./build/lan_copies 192.168.1.1              # не multicast-адрес
   ./build/lan_copies 239.192.0.1 99999        # неверный порт
   ./build/lan_copies 239.192.0.1 30000 nosuch # нет такого интерфейса
   ```
