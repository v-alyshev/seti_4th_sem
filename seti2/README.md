# tcp_file_transfer — передача файла по TCP с подсчётом скорости

Клиент передаёт серверу произвольный файл по TCP. Сервер принимает несколько клиентов параллельно, каждого в отдельном потоке, сохраняет файлы в подкаталог `uploads` и раз в 3 секунды выводит для каждого клиента мгновенную и среднюю скорость приёма. После приёма сервер проверяет, совпадает ли размер полученных данных с заявленным, и сообщает клиенту результат.

## Возможности

- Имя файла до 4096 байт в UTF-8, размер файла до 1 ТБ (2⁴⁰ байт). Ограничения проверяют и клиент, и сервер.
- Сервер работает с IPv4 и IPv6 (одним сокетом), клиент — с DNS-именем или IP-адресом.
- Параллельная работа с клиентами: на каждого — отдельный поток, главный поток сразу возвращается к приёму новых соединений. Ограничения на число клиентов нет.
- Скорость выводится раз в 3 секунды отдельно для каждого клиента. Если передача заняла меньше 3 секунд, скорость выводится один раз в конце.
- Проверка размера в обе стороны: и «пришло меньше», и «пришло больше заявленного».
- Запись только внутри `uploads`: имя очищается от каталогов и управляющих символов, файл создаётся относительно открытого каталога, симлинки не проходятся.
- Если имя занято, файл сохраняется как `имя_1.расширение`, `имя_2.расширение` и т. д.
- Неудавшиеся и неподтверждённые передачи не оставляют файлов в `uploads`.
- Ошибка одного клиента разрывает только его соединение, остальные продолжают работать.
- Плавная остановка сервера по Ctrl+C: новые клиенты не принимаются, текущие передачи завершаются.

## Требования

- Linux;
- компилятор с поддержкой C++17 (GCC 7+ или Clang 5+);
- CMake 3.10+.

```bash
sudo apt install build-essential cmake
```

## Сборка

Через CMake:

```bash
cmake -B build
cmake --build build
```

Исполняемые файлы: `build/server` и `build/client`.

## Запуск

### Сервер

```
server <порт>
```

| Параметр | Описание |
|---|---|
| порт | TCP-порт, 1–65535 |

Сервер принимает соединения на всех сетевых интерфейсах. Файлы сохраняются в `uploads` текущего каталога, каталог создаётся автоматически.

Остановка — Ctrl+C. Если идут передачи, сервер дожидается их окончания. Повторное нажатие Ctrl+C завершает сервер сразу.

### Клиент

```
client <путь к файлу> <хост> <порт>
```

| Параметр | Описание |
|---|---|
| путь к файлу | относительный или абсолютный путь к отправляемому файлу |
| хост | DNS-имя или IP-адрес сервера (IPv4 или IPv6) |
| порт | TCP-порт сервера, 1–65535 |

Серверу передаётся только имя файла, без каталогов.

### Примеры

```bash
# на машине-сервере
./build/server 5555

# на машине-клиенте
./build/client ~/video.mp4 192.168.56.11 5555
./build/client "../docs/отчет.pdf" server.local 5555
```

## Протокол

Все числа передаются в сетевом порядке байт (big-endian).

**Клиент → сервер:**

```
+---------+--------------+-----------------+---------------+-------------+
| "PROT"  | name_len u16 | name (UTF-8)    | file_size u64 | содержимое  |
| 4 байта | 2 байта      | name_len байт   | 8 байт        | file_size   |
+---------+--------------+-----------------+---------------+-------------+
```

| Поле | Размер | Значение                                  |
|---|---|-------------------------------------------|
| сигнатура | 4 байта | `PROT`; отсекает чужие подключения        |
| длина имени | 2 байта | 1–4096                                    |
| имя | 1–4096 байт | имя файла без каталогов, корректный UTF-8 |
| размер | 8 байт | размер содержимого, не больше 2⁴⁰ байт    |
| содержимое | `file_size` байт | данные файла                              |

После содержимого клиент закрывает соединение на запись (`shutdown(SHUT_WR)`), чтобы сервер мог убедиться, что лишних данных нет.

**Сервер → клиент:** один байт статуса, после чего сервер закрывает соединение.

| Значение | Смысл |
|---|---|
| `0` | файл принят полностью, размер совпал, файл сохранён |
| `1` | ошибка |

## Сохранение файлов

1. От присланного имени остаётся часть после последнего `/`.
2. Управляющие символы (`0x00`–`0x1F`, `0x7F`) заменяются на `_`.
3. Пустое имя, `.` и `..` заменяются на `upload`.
4. Имя длиннее 255 байт (лимит файловой системы) обрезается без разрыва UTF-8-символов, расширение сохраняется.
5. Файл создаётся через `openat` относительно открытого каталога `uploads` с флагами `O_CREAT | O_EXCL | O_NOFOLLOW`:
   - `O_EXCL` — только новый файл, существующие не перезаписываются;
   - `O_NOFOLLOW` — символическая ссылка в `uploads` не проходится.
6. Если имя занято, добавляется суффикс перед расширением: `отчет.pdf` → `отчет_1.pdf`.
7. Имя на диске записывается в кодировке системы сервера (на обычных системах это и есть UTF-8).

## Скорость

Скорость считается для каждого клиента отдельно, в его потоке.

```
мгновенная = байты с прошлого отчёта  / время с прошлого отчёта
средняя    = все байты сеанса         / всё время сеанса
```

- Отчёт выводится раз в 3 секунды, даже если клиент в это время ничего не присылает: ожидание данных идёт через `poll` с таймаутом до следующего отчёта.
- В конце сеанса выводится итоговый отчёт, если отчётов ещё не было или после последнего пришли новые данные. Поэтому короткая передача (меньше 3 секунд) тоже даёт одну строку скорости.
- Каждая строка начинается с адреса клиента и имени файла: `[IP:порт | имя]`.
- Единицы: меньше 1024 КБ/с — в КБ/с, иначе в МБ/с (1 КБ = 1024 байта).
- Учитываются все байты от клиента, включая заголовок.

src/

| `common/encoding.hpp/.cpp` | перекодировка имени между кодировкой системы и UTF-8 (`iconv`)              |
| `common/units.hpp/.cpp` | вывод размера и скорости в КБ/МБ                                            |
| `common/port.hpp` | проверка номера порта                                                       |
| `common/errors.hpp` | исключение с текстом `errno`                                                |
| `client/main.cpp` | точка входа                                                                 |
| `client/client_app.hpp/.cpp` | разбор аргументов, вывод результата, код завершения                         |

| `server/main.cpp` | точка входа                                                                 |
| `server/server_app.hpp/.cpp` | разбор аргументов, обработка сигналов, запуск сервера                       |

| `server/connection.hpp/.cpp` | чтение из сокета, отчёт о скорости раз в 3 секунды, таймаут бездействия     |
| `server/speed_meter.hpp/.cpp` | расчёт мгновенной и средней скорости                                        |
| `server/upload_storage.hpp/.cpp` | каталог `uploads`: создание файла с уникальным именем, удаление             |
| `server/file_name.hpp/.cpp` | очистка имени, обрезка до 255 байт                                          |
| `server/log.hpp/.cpp` | потокобезопасный вывод в консоль                                            |
